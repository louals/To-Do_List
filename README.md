## Overview

Simple to-do list app for organizing daily tasks.

## Tech Stack

Web

## Features

- Add and remove tasks
- Mark tasks complete

## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

```bash
git clone https://github.com/<your-username>/To-Do_List.git
cd To-Do_List
```
Open `index.html` in your browser. No build step required.
